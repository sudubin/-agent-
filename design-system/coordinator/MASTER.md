# 协作台界面规范

用户选择：简洁、接近 macOS 原生应用，减少装饰。当前实现是 Electron + React + CSS。

参考 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的桌面通用规则：长路径可缩短，长文本可换行，flex/grid 子元素可收缩；保留键盘焦点；状态有文字；支持减少动画；正文与按钮文字至少 4.5:1 对比度。

## 视觉约定

- 系统字体 -apple-system / PingFang SC；正文13px，辅助12px，标题按层级增大。桌面鼠标交互，主要按钮32–38px。
- 背景 #fafafa、侧栏灰色、表面白色；文字 #252528、辅助 #696973；蓝色 #0069d9，用于主要操作与焦点。
- 间距以4/8为基础；模块边距16/24，分组间距24。圆角7–10px，不使用装饰渐变或强投影。
- 布局：左侧项目，中央需求与任务，右侧真实执行现场。窄窗口允许纵向堆叠，不让长路径撑出横向滚动。
- 执行状态来自实际 controller 和 provider activity，验收完成必须来自既有报告验证。打开客户端入口不应暂停任务；需要接管同一会话时保留明确移交操作。
- Dock 图标为1024px透明画布，主体824px，四边100px透明留白。

## 检索取舍

已运行该 skill 的 design-system（minimal、density 8）、ux 横向溢出及 React 检索。采用简洁层级和溢出规则。自动生成的页面结构偏产品营销，不适合本产品的执行工作台；配色和字体按用户选择保持 macOS 风格。React 检索两次均无匹配，因此未采用该数据库的 React 建议。没有将未验证的检索结果保存为本规范。

## 验证范围

既有和新增44项前端测试、类型检查通过。真实macOS窗口需在每次打包后检查任务卡、日志展开和返回。当前只实现浅色主题，不宣称深色、移动端或完整无障碍认证已经完成。
